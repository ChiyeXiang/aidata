Connecting expertise with data production

Four roles.
Clear responsibilities.

Role separation makes professional judgment easier to inspect. Review and adjudication follow the agreed scope and project requirements.

Author

Defines the task, source materials and intended capability.

Task specification · source anchors · reference rubric

Solver

Produces a reference solution and records the steps needed to reproduce it.

Reference artifact · execution steps · assumptions

Reviewer

Independently checks correctness, evidence and adherence to the rubric.

Review record · issue classification · revision request

Adjudicator

Resolves disputed judgments and records the final rationale.

Decision rationale · rubric update · acceptance record
