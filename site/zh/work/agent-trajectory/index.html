任务理解先于规模扩张

某工具型 Agent 在文件、浏览器、代码和结构化数据之间完成长程任务，最终结果偶尔正确，但中间过程包含不稳定重试和错误来源选择。项目完整记录行动—观察链，评测员定位关键决策、工具参数、回退、自检与停止条件，并将问题区分为任务、规划、工具、执行、事实、交付物或评委层错误；高价值失败再转写为可用于后训练的修正轨迹。

04 / 返修或剔除条件

哪些问题不会进入最终批次

  • 结果正确但使用了错误或不可验证的来源
  • 无效重试掩盖了规划或工具选择错误
  • 中间状态已失败但 Agent 未触发恢复
  • 停止条件过早或提交物未满足任务验收
05 / 交付组成

最终交付不只有一列答案

  • 原始行动—观察轨迹
  • 关键节点与失败类型
  • A/B 复核及裁决记录
  • 修正轨迹与训练适用标签
