Task understanding before scale

A coding-model evaluation moved beyond short function completion into installable, interactive programs with state and error semantics. Task authors defined public behavior and locked a black-box reference. Verification engineers built hidden tests across interface, files, errors, state, boundaries and concurrency. Candidate submissions were installed, executed and retested in isolation, while independent reviewers checked grader stability.
