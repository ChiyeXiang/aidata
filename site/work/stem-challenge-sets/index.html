Task understanding before scale

A frontier-reasoning evaluation required original problems that could not be answered through search or template transfer. We defined the target capability and expected failure mode before specialists across mathematics, physics, chemistry, biology and computer science submitted prompts, complete derivations, rubrics and validation logic. A second specialist solved each task independently; model pilots, similarity search and programmatic checks removed ambiguity, contamination and accidental guessability. Volumes and pass rates are banded from a representative sanitized batch. This capability aligns to frontier scientific-reasoning methods and does not imply official affiliation with a public benchmark.

03 / FLAGSHIP CASE FILE / STEM

A case file a technical team can interrogate

Difficulty is not obscurity. A valid challenge must isolate the intended capability gap while keeping the prompt clear, the answer determinate and the derivation independently reproducible.

01

Capability slice

Work backward from model error clusters to the knowledge and reasoning boundary that needs isolation.

02

Original authoring

The specialist submits the problem, full reference, scoring rubric and validation logic as one unit.

03

Independent solve

A second specialist verifies interpretation, answer and critical intermediate results without seeing the first solution.

04

Model stress test

Repeated pilots expose shortcuts, ambiguity, accidental success and difficulty collapse.

05

Version release

Only tasks that clear originality, verifiability and difficulty gates enter the accepted batch.

04 / REWORK OR REJECTION GATES

What does not enter the accepted batch

  • Multiple valid answers or unstated assumptions
  • Reference derivation cannot be independently reproduced
  • Public retrieval or surface rewriting reveals the answer
  • Verifier checks formatting without covering the core reasoning
05 / HANDOFF PACKAGE

The handoff is more than an answer column

  • Problem and capability labels
  • Expert reference and critical steps
  • Scoring rubric and programmatic verifier
  • Independent solve, model-pilot and version records
06 / MODEL-WORKFLOW USE

Accepted tasks can support a private challenge set, capability regression testing or targeted post-training design. The final use depends on model stage and the agreed data rights.
