Task understanding before scale

A software-intelligence program needed to measure whether models could understand an unfamiliar repository, locate cross-module defects and submit complete patches without breaking existing behavior. Tasks were sanitized from authorized repository snapshots with dependencies, containers and base commits fixed. Candidate runs retained search, edit, test and recovery traces; programmatic verifiers and independent engineers jointly reviewed correctness, regression risk and completion.
