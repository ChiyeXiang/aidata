# Workflow Lab 与 Trust 页面口径

## Workflow Lab

- 路径：英文 `/lab`，中文 `/zh/lab`。
- 四套本地交互演示：金融证据、医学证据、Agent 轨迹、仓库级 SWE 验证。
- 演示只在浏览器内推进，不读取、上传或保存真实项目材料。
- 所有机构、数值、材料、来源编号、工单、环境、仓库、提交和测试结果均为虚构示例。
- 每套界面都明确显示 `DEMO / FICTIONAL DATA` 或对应中文提示，不作为客户项目、线上系统或既有业绩证明。

## Trust

- 路径：英文 `/trust`，中文 `/zh/trust`。
- 公开网站是 Vite 构建的纯静态站点，没有账户、业务数据库、服务器端表单和文件上传。
- Project Architect 默认在浏览器本地运行；未配置外部模型接口时，输入不上传、不落库，刷新后清除。
- 项目级安全、访问、工具使用、保密、留存和删除方式，需要在生产前按材料与范围逐项确认。
- 网站不声称 AxisX 已取得未公开核实的 ISO 27001、SOC 2 或其他认证。
- 客户、机构和合作 Logo 只应在关系真实且已获准公开时增加。

## 内容维护要求

如果后续替换演示数据或新增案例，请同时保留：任务对象、材料/环境版本、证据来源、异常路径、QA 状态和明确的公开边界。不要用真实客户材料替换公开演示样本。
