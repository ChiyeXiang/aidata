## 1. 交付包里有什么

|---|---|

## 3. 本地开发与构建

建议环境：Node.js 20 或 22，npm 10+。

```bash
npm ci
npm run dev
```

本地开发访问 Vite 显示的地址，并进入 `/ai/data/`。

生产构建：

```bash
npm run build
```

构建成功后应存在：

```text
dist/index.html
dist/assets/index-*.js
dist/assets/index-*.css
dist/brand/
dist/photos/
dist/work/
dist/meridian/
```

演示视频已进入 `dist/meridian/clips/`，不需要再解压第二个视频包。

如需从源码重新渲染全部视频：

```bash
npm run render:videos
```

## 4. Nginx 上线

把 `dist/` 里面的全部内容上传到：

```text
/var/www/ziwuxx.com/ai/data/
```

该目录下应直接看见 `index.html`，不要多套一层 `dist` 文件夹。

关键配置：

```nginx
location /ai/data/ {
    try_files $uri $uri/ /ai/data/index.html;
}
```

这条规则不能省略。否则直接刷新 `/ai/data/services`、`/ai/data/work/agent-evaluation`、`/ai/data/zh/services` 等前端路由会 404。

完整示例见 `nginx.example.conf`。

## 6. 后续怎么改

| 修改内容 | 文件 |
|---|---|
| 中英文主文案、能力、案例、流程、质量、领域 | `src/content.js` |
| 页面结构、路由、邮件入口、导航、页脚 | `src/main.jsx` |
| 颜色、字体、间距、响应式、动效 | `src/styles.css` |
| 部署子路径 | `vite.config.ts` |
| 图片和视频 | `public/` |
| 子午台视频生成脚本 | `scripts/render-meridian.mjs` |

不要直接修改 `dist/assets/index-*.js` 或 `index-*.css`；应该修改源码后重新执行 `npm run build`。

如果未来从 `/ai/data/` 改到其他路径，要同时修改：

1. `vite.config.ts` 的 `base`；
2. `index.html` 中 favicon 和 `og:image` 的路径；
3. Nginx 的 `location`、服务器目录与 SPA 回退地址；
4. 重新执行 `npm run build`。
