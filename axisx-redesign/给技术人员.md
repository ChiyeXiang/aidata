# AxisX / 子午象限官网 V16 — 技术交付说明

交付日期：2026-09-03  
生产地址：`https://www.ziwuxx.com/ai/data/`  
技术形态：Vite + React 纯前端 SPA；生产环境不运行 Node，不需要数据库。

## 1. 交付内容

| 路径 | 用途 |
|---|---|
| `dist/` | 已构建静态网站，可直接上传到 Nginx |
| `src/` | React 页面、路由、中英文内容与视觉系统 |
| `public/` | 品牌标识、工作流海报、案例视频与页面背景视频 |
| `scripts/render-meridian.mjs` | 全部中英文视频和海报生成脚本 |
| `scripts/assets/` | 视频渲染所需字体 |
| `vite.config.ts` | `dist` 输出和 `/ai/data/` 部署子路径 |
| `nginx.example.conf` | SPA fallback 与缓存配置 |

`node_modules/` 不进入交付包，执行 `npm ci` 即可恢复。

## 2. V16 业务体系

- 首页将能力收敛为专家知识系统、Agent 与后训练数据、可执行 Benchmark 工程三套产品系统，避免能力清单过散。
- 首页新增面向模型与研究、数据与运营、采购与项目负责人的三个角色入口，分别连接旗舰案例、交付体系和 Project Architect。
- 新增 `/methodology` 与 `/zh/methodology` 数据方法页面，说明能力增量、任务有效性、过程证据、可复现性与分歧裁决五项原则。
- 数据方法页同时说明一条复杂数据单元的六层组成，以及“定义边界—构造任务—独立验证—模型压力测试—版本发布—回到模型”的持续闭环。

- STEM 原创 Challenge Set：数学、物理、化学、生物、计算机科学专家原创出题。
- 每道题配套参考推导、评分量规、答案唯一性检查和符号、数值或程序化验证器。
- 通过独立专家复算、模型试跑、难度分层、可检索性与污染风险筛查验证任务有效性。
- 金融、法律、医学任务保留来源证据、专业边界、双评与领域裁决。
- Agent 任务记录计划、工具调用、观察、回退、修正、停止条件与失败归因。
- MLE / MLS 评测覆盖环境、实验、产物、指标、消融、泛化证据与独立复跑。
- ProgramBench、DeepSWE、FrontierSWE 型任务覆盖程序行为重建、真实仓库长程工程、隐藏测试和程序化验证。
- 地学任务覆盖测井、岩芯、层位、图件与报告的多源对齐；教育任务覆盖课程知识图谱、原创题目、步骤量规和难度校准。
- 首页网络数据为 102+ 院校与研究机构关系、3,000+ 经筛选人才网络、2,000+ 工程与 ML 人才、1,000+ 硕博及垂类专家；同时显示统计口径、滚动更新时间与非同时在岗说明。
- 10 个代表案例统一使用“能力缺口—评测对象—任务设计—代表规模—QA 协议—证据包—公开边界”结构，客户身份、输入内容及部分规模指标已移除或区间化。
- STEM 与 Agent 详情页增加旗舰案例档案，说明能力切片、五步执行、返修或剔除门槛、交付组成和模型工作流用途。
- 首页试点入口明确适用场景、客户输入和首轮交付物，便于采购、算法和数据团队快速建立最小验证批次。
- 新增 `/architect` 与 `/zh/architect` Project Architect 页面：默认通过浏览器端规则化规划模型生成项目蓝图，不提交表单、不保存输入、不依赖数据库。
- Project Architect 覆盖金融、法律、医学、STEM、Agent、MLE / MLS、ProgramBench、FrontierSWE、地学与教育，输出任务单元、专家配置、证据包、执行路径、验收信号、试点范围和风险边界。
- 规划结果可以直接生成一封简要合作邮件，不提供复制、打印或导出入口。
- 首页、能力、交付、案例、Meridian、Workflow Lab、Project Architect、质量、Trust、Roadmap、公司和联系页均有中英文完整叙事。

公开 Benchmark 名称只描述可对齐的任务方法；除非另有明确说明，不宣称官方合作、授权或所有权。医学内容不提供临床诊断，法律内容不替代法律意见。

## 3. 视频系统

```bash
npm run render:videos
```

生成内容：

- 20 个中英文案例/模块视频：金融、法律、医学、STEM、Agent 轨迹、MLE / MLS、ProgramBench、DeepSWE / FrontierSWE、地学、教育
- 2 个中英文工作流总览视频
- 10 个中英文页面背景视频：首页、能力、案例、Meridian、未来
- 20 张中英文案例与模块海报

目录：

```text
public/meridian/clips/
public/meridian/backgrounds/
public/meridian/v10/
```

网页中的 `<video>` 均使用 `autoplay muted loop playsinline`，没有 `controls`、播放按钮或播放器边框。案例/模块视频和背景视频均为 11 秒，总览视频超过 24 秒。每个案例使用独立中心工作区、流程队列、验收面板和主题色；鼠标、进度、证据同步、审核状态与运行时间连续变化，不使用原先的静态画面加黑场翻页。进入或接近视口的视频自动播放，远离视口时通过 `IntersectionObserver` 暂停，以降低多视频页面的解码和耗电压力。

## 3.1 全站环境背景动效

- 首页、能力、交付、案例、案例详情、Meridian、质量、未来、公司、联系及 404 均通过 `PageBackdrop` 配置独立背景图。
- 视觉由业务工作台海报、边缘蒙版、低透明度网格和轨道光点组合，不使用人物办公场景，不影响正文交互。
- 桌面端包含缓慢景深漂移与滚动视差；移动端自动降低透明度与运动范围。
- `prefers-reduced-motion: reduce` 下全部背景动画停止，保留静态视觉层。
- 路由与图片映射位于 `src/main.jsx` 的 `PageBackdrop`；案例、视频、Workflow Lab 与 Project Architect 视觉位于 `src/styles.css` 的版本化区域。

## 5. Nginx 上线

把 `dist/` 内全部内容上传到：

```text
/var/www/ziwuxx.com/ai/data/
```

关键 fallback：

```nginx
location /ai/data/ {
    try_files $uri $uri/ /ai/data/index.html;
}
```

这条规则不能省略，否则刷新案例详情或双语深层路由会 404。完整配置见 `nginx.example.conf`。
