# AxisX / 子午象限官网 V8

纯前端 Vite + React 项目，生产环境只需 Nginx 静态托管。

```bash
npm ci
npm run dev
npm run build
npm run preview
```

默认英文首页：`/ai/data/`；右上角“中文”进入 `/ai/data/zh`。

如需重新生成子午台的 10 个中英文模块视频与 2 个总览视频：

```bash
npm run render:videos
```

联系页没有网页表单或数据库写入，项目材料通过访客自己的邮件客户端发送至 `kevin@ziwuxx.com`。

V5 进一步优化了国际化 UX、中文字体与标题断行，首屏换为多任务数据运营场景，并在各核心分页补充了产品界面、质量证据和方法说明。未来页新增虚拟场景、合成数据、Benchmark 与评测原生数商方向。

V7 完成最终编辑式科技升级：首页“代表交付”收敛为完整的四案例矩阵，移除视觉空位；每个案例新增交付组织方式、完整项目介绍与三项质量证据。第四张新增具身智能动作语义数据案例与独立场景图，并统一强化酸性绿、深紫、精密边线、错位节奏与产品证据感。

V8 增加克制的功能型动效：页面滚动分层进入、首屏轻微视差、数据数字递增、案例卡状态反馈、页面切换信号与子午台视频运行扫描。手机端降低动效强度，并完整支持系统“减少动态效果”设置。
