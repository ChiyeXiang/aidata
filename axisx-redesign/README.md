# AxisX / 子午象限官网 V16

纯前端 Vite + React SPA，生产环境只需 Nginx 静态托管；部署子路径固定为 `/ai/data/`。

```bash
npm ci
npm run dev
npm run build
npm run preview
```

默认英文首页：`/ai/data/`；右上角“中文”进入 `/ai/data/zh`。

重新生成全部 Meridian 视觉资产：

```bash
npm run render:videos
```

V16 延续三套可采购、可验收的产品系统：专家知识系统、Agent 与后训练数据、可执行 Benchmark 工程；同时增加独立的中英文数据方法页面、首页采购角色入口，以及两个旗舰案例档案。核心定位仍是“高难度专家知识、Challenge Set 与模型反馈基础设施”：

- 数学、物理、化学、生物与计算机科学原创 STEM 难题
- 参考推导、评分量规、程序化验证器、难度校准与污染风险筛查
- 金融、法律、医学来源级专家数据与 Golden Set
- 模型后训练、Agent 轨迹与失败归因
- MLE / MLS 可复现实验评测
- ProgramBench、DeepSWE 与 FrontierSWE 型可执行软件智能评测
- 地学多源资料解释与教育任务、学习诊断等垂类知识工作
- 任务、环境、运行证据、独立复核、裁决与持续 Benchmark 版本

不再公开展示 2D、3D 点云等基础劳动密集任务。页面中的公开 Benchmark 名称仅描述可对齐的任务方法，不代表官方合作或所有权。

首页展示 102+ 院校与研究机构关系、3,000+ 经筛选人才网络、2,000+ 工程与 ML 人才及 1,000+ 硕博、医生、律师和垂类专家的保守下限口径，并新增统计定义、滚动更新时间与非同时在岗说明。

10 个案例均提供独立的中文与英文操作工作流，内容统一为“能力缺口、评测对象、任务设计、代表规模、QA 协议、证据包、公开边界”，并对客户身份、输入材料与部分指标作脱敏或区间化处理。STEM 与 Agent 两个旗舰案例进一步说明能力切片、执行步骤、返修门槛、交付组成及进入模型工作流的方式。

新增 `/methodology` 与 `/zh/methodology` 数据方法页面，从能力增量、任务有效性、过程证据、可复现性和分歧裁决五个维度说明 AxisX 对高质量数据的判断。页面同步展示一条复杂数据单元的必要组成，以及从能力定义到模型反馈的六阶段闭环。

首页新增三个采购角色入口，分别面向模型与研究团队、数据与运营团队、采购与项目负责人。每个入口使用不同的问题、验收信号和目标页面，减少所有访客阅读同一套泛化介绍的成本。

全部视频静音自动循环、无播放器控件；20 个双语案例/模块视频均为 11 秒，10 个双语背景视频均为 11 秒，2 个总览视频均超过 24 秒。金融、医学、代码、Agent 等模块采用独立流程命名、验收面板与视觉主题，离开视口的视频会自动暂停以降低资源占用。

首页增加试点合作入口，以“适合启动—需要提供—首轮返回”说明最小验证批次，帮助采购与技术团队快速判断合作边界。

中英文 Project Architect 允许访客选择领域、项目类型、模型阶段和合作尺度，并在浏览器本地生成任务单元、专家配置、证据包、执行路径、验收信号、试点范围和主要风险。默认模式不登录、不上传、不保存，也不需要数据库；下一步直接通过邮件沟通。

V16 的中英文 Workflow Lab 覆盖金融长上下文证据、医学循证与安全、Agent 轨迹恢复、仓库级软件验证。四套界面使用不同的任务对象、版本记录、复核分歧、裁决逻辑与 QA 流程；Agent 支持原始轨迹和修正轨迹切换，SWE 展示连续测试日志。演示可自动循环、暂停、点选步骤和重跑，不提供材料片段展开或导出功能。

中英文 Trust 页面只说明当前公开网站已经实现的机制，以及可以在具体项目中书面落地的运营控制。页面不虚构 ISO 27001、SOC 2 等认证，也不使用未经许可的客户或合作 Logo。

页面视觉不使用生成式人物、虚假办公场景或装饰性机器人图。公司页、质量页和全站环境背景统一改用任务工作台、证据面板与运行界面。

如需接入真实模型，可以在构建时配置 `VITE_ARCHITECT_API_URL`。前端会调用无状态模型接口；接口不可用时自动回退本地规划模式。模型 Key 必须保存在服务端，详细契约与安全要求见 [`ARCHITECT_API.md`](./ARCHITECT_API.md)。

最终版为每条路由增加独立环境背景：业务画面以边缘蒙版、轻景深漂移、网格位移和轨道光点呈现；移动端降低强度，系统开启“减少动态效果”时自动静止。
