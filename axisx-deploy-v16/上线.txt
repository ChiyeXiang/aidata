AxisX / 子午象限官网 V16

最快上线方式：
1. 将 axisx-deploy-v16/site/ 内全部内容上传至 /var/www/ziwuxx.com/ai/data/
2. 使用 axisx-deploy-v16/nginx.example.conf 配置静态托管和 SPA fallback
3. 执行 nginx -t，确认无误后 reload Nginx
4. 检查英文首页 /ai/data/、中文首页 /ai/data/zh 和深层案例路由
5. 检查背景与模块视频均自动静音循环且无播放控件
6. 检查英文 /ai/data/architect 与中文 /ai/data/zh/architect；默认本地规划模式不需要数据库
7. 检查 /ai/data/lab、/ai/data/zh/lab、/ai/data/trust 和 /ai/data/zh/trust 可直接刷新
8. 检查 /ai/data/methodology、/ai/data/zh/methodology 及两个旗舰案例详情可直接刷新

这是纯静态 Vite + React 网站，不需要运行 Node、数据库或后端服务。
完整说明和验收清单见 给技术人员.md。
